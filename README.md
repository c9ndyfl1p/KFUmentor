# matchmentor

**Career search, with a mentor.**

matchmentor — локальное приложение для поиска работы и развития карьеры. Оно помогает подобрать вакансии на hh.ru, сопоставить их с профилем, подготовить тексты для общения с работодателями и составить план обучения.

Приложение запускается на компьютере пользователя и открывается в браузере. Разделы панели: **Поиск**, **Ответ HR**, **Ментор** и **Профиль**.

## Что умеет приложение

### Поиск работы

- Ищет вакансии на hh.ru по должности, задаче и выбранному городу или региону.
- Оценивает совпадение вакансии с профилем по шкале от 0 до 10.
- Показывает текущий анализ, ошибки и результаты, достигшие выбранной минимальной оценки.
- Считает лимит как количество вакансий, прошедших минимальную оценку. Например, при лимите 10 агент продолжает поиск, пока не найдёт 10 подходящих вакансий или не исчерпает доступные результаты.
- Показывает этап обработки каждой найденной вакансии; карточку можно открыть на hh.ru.
- По желанию отправляет отклики. Автоотклики выключены по умолчанию; правила отправки зависят от выбранного режима (см. ниже).
- Если поле сопроводительного письма недоступно в форме отклика, пытается добавить письмо через чат отклика.
- Позволяет остановить поиск и вручную войти в hh.ru. При появлении CAPTCHA приложение показывает предупреждение и ждёт ручного решения.

Проверяйте статус отклика и переписку в аккаунте hh.ru: сайт может менять формы и требовать дополнительных действий.

### Ответ HR

По вакансии, компании, сообщению HR и дополнительному контексту приложение готовит черновик ответа. Его можно отредактировать, скопировать и отправить вручную. Приложение не отправляет ответы работодателям автоматически.

### Карьерный ментор

- Анализирует профиль в целом или относительно описания целевой вакансии.
- Выявляет сильные стороны и пробелы, задаёт уточняющие вопросы и пересматривает оценку после ответа.
- Составляет план развития на ближайшие недели с шагами и отметками прогресса.
- Создаёт практическое задание и разбирает ответ.
- Проводит тренировочное интервью: задаёт вопросы по одному и оценивает ответы.
- Готовит черновик адаптированного резюме. Факты нужно проверить перед использованием.

План, задания и прогресс ментора сохраняются на компьютере пользователя.

### Профиль и резюме

Профиль кандидата можно заполнить вручную или импортировать из JSON, текстового PDF либо DOCX. Для PDF и DOCX требуется доступная модель. После разбора резюме данные открываются для проверки и сохраняются только после подтверждения пользователем. Сканы PDF без текстового слоя и старый формат DOC не поддерживаются.

## Быстрый запуск

### Требования

- Go 1.24.3 или новее.
- Chromium, установленный через Playwright.
- Доступ к hh.ru и к выбранной модели.

Установите Chromium из корня проекта:

```bash
go run github.com/mxschmitt/playwright-go/cmd/playwright@v0.6201.1 install chromium
```

Для стандартного запуска с DeepSeek используйте скрипт:

```bash
./scripts/run-with-deepseek.sh
```

Скрипт запускает локальный мост DeepSeek, если он ещё не работает, и затем открывает панель на [http://127.0.0.1:8787](http://127.0.0.1:8787). Мост должен быть настроен заранее: по умолчанию скрипт ищет соседнюю папку `DeepSeek-Api-Free` с `.env` и виртуальным окружением `.venv`. Другую папку можно указать переменной `DEEPSEEK_BRIDGE_DIR` или файлом `scripts/.deepseek-bridge-path.local`.

В `.env` моста задайте `API_KEY`, `HOST=127.0.0.1`, `MEMORY_MODE=client` и `HEADLESS=false`. При первом использовании войдите в DeepSeek в открывшемся окне. Сессия браузера хранится локально.

Для ручного запуска панели без скрипта:

```bash
go run . --web
```

В этом случае DeepSeek bridge должен быть запущен отдельно и доступен по адресу `http://127.0.0.1:8000/v1`. Панель слушает только локальный компьютер. Остановить её можно сочетанием `Ctrl+C` в терминале.

## Как начать работу

1. Откройте **Профиль**, заполните данные кандидата или прикрепите резюме, проверьте результат и сохраните профиль.
2. В **Поиске** укажите должность и условия. Выберите город из подсказок или оставьте поле пустым для поиска по России.
3. Укажите лимит подходящих вакансий и минимальную оценку соответствия от 0 до 10. При оценке 0 порог отключён.
4. При первом входе нажмите **«Только войти на hh.ru»** и авторизуйтесь вручную. Поиск после входа автоматически не начинается.
5. Оставьте автоотклики выключенными для обычного поиска. Включайте их отдельно, если хотите отправлять отклики; проверяйте результат на hh.ru.
6. Используйте **Ответ HR** для подготовки черновика ответа, а **Ментор** — для оценки навыков, плана и практики.

## Проверка содержания резюме и писем

Принимаются только резюме и рабочие сопроводительные письма. Посторонняя агитация, реклама, угрозы, оскорбления, инструкции для обхода модели и другие нарушения политики блокируют документ целиком. Нейтральный профессиональный опыт, включая работу в госорганизациях, сам по себе не запрещён. Недостающие навыки не являются нарушением этой проверки.

- Загружайте PDF с выделяемым текстом, DOCX или JSON, **без фото и изображений**. Изображения, вложения, формы, комментарии, непринятые исправления Word и непроверяемые встроенные объекты отклоняются. Некоторые сложные PDF с текстом внутри графических объектов тоже потребуют пересохранения в простой текстовый документ.
- Исходный извлечённый текст проверяется до разбора; полученный профиль — после разбора и при каждом сохранении, включая ручное редактирование. JSON также требует проверки моделью.
- Перед поиском проверяется используемый профиль, перед отправкой — профиль и точный текст письма. Ранее подтверждённый черновик не освобождается от проверки содержания. Автоматический и ручной отклики используют одну проверку перед первым нажатием кнопки отклика.
- При отказе показывается причина. При недоступной модели, неясном или некорректном ответе сохранение/отправка блокируются; прежний профиль сохраняется. Повторите действие после исправления текста или восстановления модели.
- Успешная проверка повторно используется не более 30 минут в текущем процессе только для неизменённого текста, типа документа и версии политики. Изменение любого поля или письма требует новой проверки. После перезапуска проверка выполняется заново.

Второй этап добавляет проверочные представления Unicode NFKC, похожих букв/цифр в русских словах, разорванных слов, HTML/URL-кодирования и читаемых Base64/hex-фрагментов. Это ограниченные эвристики, а не полный декодер всех способов маскировки. Оригинальный профиль и письмо не переписываются; модель сравнивает представления с исходником. Проверка скрытых символов выполняется также в декодированных JSON-значениях. При слишком большом объёме маскировки требуется обычный читаемый текст. Ожидание очереди проверки отменяется по контексту запроса. Ошибки различают недоступность, неправильный ответ, непрочитанный текст и отказ по политике.

Политика и строгая схема ответа находятся в `internal/contentcheck/check.go`. Проверка содержания отделена от оценки вакансии и проверки фактов. Это защитный фильтр, а не гарантия безошибочной классификации или юридическая экспертиза. Оригинальные документы не рассылаются: используются извлечённый профиль и текст письма. Ссылки проверяются как текст; содержимое внешних сайтов не загружается. Для публичного сервиса нужен обязательный контроль на сервере: владелец локальной копии может изменить её код.

Автотесты проверяют блокировки и целостность потока. Отдельный тест `TestLiveContentPolicy` проверяет восемь синтетических примеров реальной моделью; включается через `KFUMENTOR_CONTENT_MODEL_SMOKE=1`, `KFUMENTOR_CONTENT_MODEL_URL` и `KFUMENTOR_CONTENT_MODEL_NAME`, ключ задаётся обычной переменной `AI_JOB_AGENT_MODEL_API_KEY`. Он не выполняет настоящих откликов.

## Персональные данные

Профиль, план ментора и сессия hh.ru хранятся на компьютере пользователя. Файл резюме используется для извлечения данных и не сохраняется приложением как исходный файл. Для анализа и генерации нужные поля профиля, тексты вакансий и сообщения передаются DeepSeek через подключённый мост и обрабатываются инфраструктурой DeepSeek. Мост работает на компьютере пользователя, но это не означает, что сама модель работает локально.

В нижней части приложения доступны документы **«Политика обработки персональных данных»** и **«Согласие на обработку персональных данных»**. Это шаблоны для локальной версии, а не юридическое подтверждение соответствия требованиям 152-ФЗ и не зафиксированное приложением согласие. До публичного запуска оператору нужно заполнить данные и проверить документы по фактической схеме обработки, включая используемого AI-провайдера. Приложение пока не фиксирует подписание согласия.

Локальные пользовательские данные исключены из Git. Не добавляйте в репозиторий резюме, cookies, пароли, API-ключи или данные других людей.

## Где находятся локальные данные

- Профиль: `data/resume.local.json`.
- План и прогресс ментора: `data/mentor.plan.json`.
- Сессия браузера hh.ru: `~/.ai-job-agent/profile`.
- Личные примеры сопроводительных писем, если созданы: `data/cover-letter-examples.local.json`.

## Ограничения

- Проект работает локально и не имеет общей базы аккаунтов или синхронизации между пользователями.
- Поиск, оценка, разбор резюме и функции ментора требуют доступной модели.
- Содержимое ответов модели может быть неточным. Проверяйте оценки, советы, письма и все факты в адаптированном резюме.
- hh.ru может менять интерфейс, ограничивать автоматизацию, запрашивать CAPTCHA или требовать ручного подтверждения. Автоматизация поддерживает основные сценарии, но не гарантирует успешный отклик для каждой вакансии.
- Отклики отправляются только при включённой настройке. Ответы в чаты работодателей автоматически не отправляются.

## Запуск из терминала

Поиск без автооткликов:

```bash
go run . --task="найди вакансии Go-разработчика в Казани" --headless=false
```

Включить автоотклики:

```bash
go run . --task="найди вакансии Go-разработчика в Казани" --headless=false --auto-apply
```

Открыть hh.ru для ручного входа:

```bash
go run . --login-only
```

Основные параметры: `--web`, `--web-addr`, `--task`, `--headless`, `--auto-apply`, `--application-target`, `--vacancy-limit`, `--min-score`, `--profile`, `--resume`, `--model-url`, `--model`, `--area`, `--login-only`.

### Правила откликов и ручная проверка

Автоотклики включаются отдельно. Тумблер находится в «Точных настройках»: слева **По оценке**, справа **По рекомендации модели**. При первом открытии выбран режим по рекомендации; браузер запоминает последующий выбор.

- По оценке: все корректно оценённые вакансии с баллом от порога допускаются к автоотклику независимо от `apply`, `review` или `skip`.
- По рекомендации модели: `apply` допускается к автоотклику независимо от балла. Для `review` от выбранного порога доступны объяснение спорных моментов и кнопка **Откликнуться**.
- Эта кнопка только ставит подготовку письма в очередь и открывает предпросмотр. Реальная отправка требует отдельного нажатия **Отправить** и работает даже при выключенных автооткликах. В отправку идёт просмотренный текст; изменение профиля требует нового предпросмотра.
- Очередь выполняется между вакансиями; один браузер не обслуживает два действия одновременно. Ручные и автоматические отклики учитываются в одной цели текущего запуска. После достижения цели лишние отправки блокируются.
- Не загруженное описание, недоступная модель, неверный JSON, отсутствие или некорректные поля решения блокируют отправку. Ошибку можно исправить кнопкой **Повторить оценку**; повторная оценка сама по себе не разрешает отправку.
- Сопроводительное проверяется на неподтверждённые факты. Подтверждённый отклик без письма учитывается как отправленный, показывается предупреждение, поиск продолжается. Если результат отправки неизвестен, повтор заблокирован до ручной проверки на hh.ru.
- Отсутствие навыков из вакансии не запрещает ручной отклик. Проверка письма ищет выдуманные утверждения о кандидате, а не требует полного соответствия вакансии. Если автопроверка письма не завершилась, для ручного просмотра готовится короткий текст по фактам профиля с предупреждением; отправить его можно отдельным подтверждением пользователя. Автоматическая отправка при таком сбое остаётся заблокированной.
- Проверка/подготовка привязывается к точному тексту письма и версии профиля. При ручном подтверждении того же черновика повторное разрешение модели не запрашивается. Изменение профиля требует новой подготовки письма. Старые черновики без отметки подготовки проверяются при отправке; при отказе подготовьте новую версию.

История карточек, очередь, просмотренные письма и состояния отправок хранятся в `data/application-history.local.json` (исключён из Git). Запись атомарная с блокировкой между процессами. После перезапуска неподтверждённые команды отправки не выполняются автоматически; отправка, прерванная во время выполнения, помечается как неопределённая. Очередь поддерживается на macOS и Linux.

Профиль хранится локально, но данные для анализа и генерации передаются выбранной модели; при мосте DeepSeek — сервису DeepSeek. Работа форм hh.ru и правильность анализа модели требуют проверки пользователем.

### Проверка качества оценки

В `internal/browser/testdata/evaluation_cases.json` находится набор синтетических контрольных вакансий с ожидаемыми диапазонами баллов и рекомендациями. Опциональный тест `TestDeepSeekEvaluationBenchmark` обращается к реальной модели только при `KFUMENTOR_DEEPSEEK_BENCHMARK=1`, использует вымышленное резюме и не открывает hh.ru/не отправляет отклики. Эти ожидания — ручная разметка тестового набора, не доказательство точности на всех вакансиях.

Для оценки передаются все навыки и разделы резюме, а также полное поддерживаемое описание вакансии. Обязательные требования не отбрасываются по позиции в тексте. При слишком большом входе программа выдаёт ошибку вместо молчаливого усечения. Контактный раздел исключён.

Скрипт моста задаёт минимум 12 секунд между началами запросов модели через `AI_JOB_AGENT_MODEL_REQUEST_INTERVAL_SECONDS`; общий файл `data/model-rate.local.json` координирует сервер и процесс агента. Это снижает вероятность ограничения частоты браузерного DeepSeek, но не гарантирует доступность сервиса.

### Сбор вакансий Хабр Карьеры

В разделе «Поиск вакансий» доступен отдельный блок «Хабр Карьера · Сбор вакансий».
Вставьте ссылку `https://career.habr.com/vacancies` с нужными фильтрами или ссылку
на отдельную вакансию и задайте лимит от 1 до 100. Сбор сохраняет фильтры при
переходе между страницами, убирает дубли и загружает полные описания.
Карточки содержат компанию, зарплату работодателя (без рыночного прогноза сайта),
уровень, требования и условия. Это этап сбора без оценки моделью и без откликов.
Количество означает число собранных карточек, включая карточки с ошибкой чтения.

Результаты сохраняются в `data/habr-vacancies.local.json` и доступны после
перезапуска. Новый сбор заменяет подборку; остановка сохраняет уже полученные
карточки. Сбор ограничен 100 вакансиями, 20 страницами и 10 минутами за запуск.
Нужен установленный Chromium Playwright, как и для основного приложения.

Проверки публичных страниц (без авторизации и отправки форм):
`HABR_BROWSER_TEST=1 HABR_LIVE_TEST=1 go test ./internal/habr -v`.
