# AI Job Agent

Локальный MVP для поиска вакансий на hh.ru и первичной оценки их соответствия профилю кандидата. Проект написан на Go, управляет Chromium через Playwright и обращается к локальной модели Ollama.

## Что работает сейчас

- Поиск вакансий на hh.ru по запросу.
- Извлечение карточек вакансий и оценка соответствия через Ollama.
- Подготовка сопроводительного письма.
- Отправка откликов только при явном включении `--auto-apply`.
- Постоянный профиль Chromium для входа пользователя в hh.ru.
- Профиль кандидата загружается из JSON, а не зашит в исходный код.

Это пока не автономная платформа из концепции: нет регистрации и кабинета, базы данных кандидатов, очереди фоновых задач, интеграций с почтой/календарём, HR-переписки, подготовки и аналитики интервью, сопровождения офферов и биллинга. Браузерная автоматизация может ломаться при изменениях сайта. CAPTCHA и запросы на подтверждение нужно проходить вручную.

## Подключение ИИ через Ollama

Агент уже использует Ollama как ИИ-сервер: отдельный API-ключ для локальной модели не нужен. Модель работает на вашем компьютере; для её первоначальной загрузки нужен интернет. Этот проект вызывает Ollama API (`/api/generate` и `/api/chat`), а не ChatGPT/OpenAI API.

1. Установите Ollama с [официального сайта](https://ollama.com/download).
2. Откройте приложение Ollama. Если вы запускаете Ollama из терминала и сервер ещё не работает, выполните `ollama serve` в отдельном окне терминала.
3. Загрузите модель, которую проект использует по умолчанию:

   ```bash
   ollama pull qwen2.5:7b
   ```

   Файл модели занимает около 4,7 ГБ; понадобятся дополнительное место для временных файлов и память для запуска модели. [Страница модели и варианты размеров](https://ollama.com/library/qwen2.5).

4. Убедитесь, что Ollama запущен и модель установлена:

   ```bash
   ollama list
   curl http://localhost:11434/api/tags
   ```

5. Запустите панель проекта:

   ```bash
   go run . --web
   ```

   Откройте [http://localhost:8787](http://localhost:8787). При запуске приложение подключится к Ollama по адресу `http://localhost:11434` и будет использовать `qwen2.5:7b`.

Если выбрали другую модель, сначала загрузите её командой `ollama pull ИМЯ_МОДЕЛИ`, затем передайте это же имя приложению. Например:

```bash
go run . --web --model=qwen2.5:3b
```

Если Ollama работает на другом адресе или порту, укажите базовый адрес без `/api`:

```bash
go run . --web --model-url=http://127.0.0.1:11434 --model=qwen2.5:7b
```

В локальной панели адрес и модель не задаются; их нужно указать в команде до запуска панели. Адрес `--model-url` должен быть доступен именно той машине, где выполняется агент. При ошибке соединения проверьте, что Ollama запущен, `ollama list` показывает нужную модель, а сервер принимает запросы на `11434`.

## Требования

- Go 1.24 или новее.
- Ollama и загруженная модель, например `qwen2.5:7b` (инструкция выше).
- Chromium/Playwright. При первом запуске библиотека Playwright может установить драйвер; браузер устанавливается командой ниже.

```bash
go run github.com/mxschmitt/playwright-go/cmd/playwright@v0.6201.1 install chromium
```

На Linux системные библиотеки Chromium при необходимости установите по инструкциям Playwright для вашей ОС.

## Профиль кандидата

Отредактируйте `data/resume.json` или создайте отдельную копию профиля. Файл должен содержать ваши реальные данные; пример в репозитории демонстрационный. Не коммитьте персональный профиль.

```json
{
  "name": "Имя Фамилия",
  "title": "Backend-разработчик",
  "summary": "Краткое профессиональное описание",
  "experience": [
    {
      "position": "Backend-разработчик",
      "company": "Компания",
      "period": "2022–2025",
      "responsibilities": ["Разрабатывал сервисы на Go", "Поддерживал PostgreSQL"]
    }
  ],
  "skills": ["Go", "PostgreSQL", "Docker"],
  "education": [],
  "languages": [],
  "contact": {
    "email": "name@example.com",
    "phone": "+7 ...",
    "linkedin": "",
    "github": ""
  }
}
```

Перед отправкой откликов программа проверяет наличие имени, должности и навыков. Персональные поля из этого файла не используются для входа в аккаунт: авторизуйтесь вручную в открытом Chromium.

## Использование

### Локальная панель управления

Запустите из корня проекта:

```bash
go run . --web
```

Откройте [http://localhost:8787](http://localhost:8787). В панели можно заполнить профиль, запустить поиск, посмотреть вывод агента и отдельно включить автоотклики. Чтобы войти в hh.ru без запуска поиска, нажмите **«Только войти на hh.ru»**. Агент откроет отдельное окно и не будет переключать страницу или продолжать поиск; после входа закройте окно, чтобы сохранить сессию. В разделе профиля нажмите **«Прикрепить резюме»**, чтобы импортировать JSON-профиль размером до 1 МБ; формат полей показан в примере ниже. PDF и DOCX пока не импортируются. Профиль из панели хранится в `data/resume.local.json` и не попадёт в Git.

Остановить локальный сервер: `Ctrl+C` в терминале.

Запустить панель на другом локальном порту можно так:

```bash
go run . --web --web-addr=127.0.0.1:9000
```

Интерфейс доступен только на локальном компьютере.

### Командная строка

Сначала запустите поиск без отправки откликов:

```bash
go run . --task="найди вакансии Go-разработчика в Москве" --headless=false
```

Открыть hh.ru только для ручного входа, без поиска:

```bash
go run . --login-only
```

При первом запуске войдите в hh.ru в открытом браузере. Сессия хранится локально в `~/.ai-job-agent/profile`.

Для явной отправки откликов по результатам AI-оценки:

```bash
go run . --task="найди вакансии Go-разработчика в Москве" --headless=false --auto-apply
```

Укажите другой профиль кандидата или сервер/модель Ollama:

```bash
go run . --task="найди удалённую работу" --resume="./my-resume.json" --model-url="http://localhost:11434" --model="qwen2.5:7b"
```

Основные параметры: `--web`, `--web-addr`, `--task`, `--headless`, `--auto-apply`, `--debug`, `--profile`, `--resume`, `--model-url`, `--model`, `--interactive`.

## Безопасное использование

- По умолчанию `--auto-apply` выключен. Без флага сгенерированный AI-план не отправляет отклики.
- Сначала проверяйте вакансии и письма вручную; модель может ошибаться.
- Не храните в репозитории персональные данные, cookies или другие секреты.
- Не обходите CAPTCHA и ограничения сайта; если сайт просит подтверждение, выполните его вручную.
