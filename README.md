# matchmentor

**Career search, with a mentor.**

matchmentor — локальное приложение для поиска работы и развития карьеры. Оно помогает подобрать вакансии на hh.ru, сопоставить их с профилем, подготовить тексты для общения с работодателями и составить план обучения.

Приложение запускается на компьютере пользователя и открывается в браузере. Разделы панели: **Поиск**, **Ответ HR**, **Ментор** и **Профиль**.

## Что умеет приложение

### Поиск работы

- Ищет вакансии на hh.ru по должности, задаче и выбранному городу или региону.
- Оценивает совпадение вакансии с профилем по шкале от 0 до 10.
- Показывает в ходе поиска только вакансии, достигшие выбранной минимальной оценки.
- Считает лимит как количество вакансий, прошедших минимальную оценку. Например, при лимите 10 агент продолжает поиск, пока не найдёт 10 подходящих вакансий или не исчерпает доступные результаты.
- Показывает этап обработки каждой найденной вакансии; карточку можно открыть на hh.ru.
- По желанию отправляет отклики. Автоотклики выключены по умолчанию; перед отправкой агент должен получить подходящую оценку и рекомендацию модели.
- Если поле сопроводительного письма недоступно в форме отклика, пытается добавить письмо через чат отклика.
- Позволяет остановить поиск и вручную войти в hh.ru. При появлении CAPTCHA приложение показывает предупреждение и ждёт ручного решения.

Проверяйте статус отклика и переписку в аккаунте hh.ru: сайт может менять формы и требовать дополнительных действий.

### Ответ HR

По вакансии, компании, сообщению HR и дополнительному контексту приложение готовит черновик ответа. Его можно отредактировать, скопировать и отправить вручную. Приложение не отправляет ответы работодателям автоматически.

### Карьерный ментор

- Анализирует профиль в целом или относительно описания целевой вакансии.
- Выявляет сильные стороны и пробелы, задаёт уточняющие вопросы и пересматривает оценку после ответа.
- Составляет план развития на ближайшие недели с шагами и отметками прогресса.
- Создаёт практическое задание и разбирает ответ.
- Проводит тренировочное интервью: задаёт вопросы по одному и оценивает ответы.
- Готовит черновик адаптированного резюме. Факты нужно проверить перед использованием.

План, задания и прогресс ментора сохраняются на компьютере пользователя.

### Профиль и резюме

Профиль кандидата можно заполнить вручную или импортировать из JSON, текстового PDF либо DOCX. Для PDF и DOCX требуется доступная модель. После разбора резюме данные открываются для проверки и сохраняются только после подтверждения пользователем. Сканы PDF без текстового слоя и старый формат DOC не поддерживаются.

## Быстрый запуск

### Требования

- Go 1.24.3 или новее.
- Chromium, установленный через Playwright.
- Доступ к hh.ru и к выбранной модели.

Установите Chromium из корня проекта:

```bash
go run github.com/mxschmitt/playwright-go/cmd/playwright@v0.6201.1 install chromium
```

Для стандартного запуска с DeepSeek используйте скрипт:

```bash
./scripts/run-with-deepseek.sh
```

Скрипт запускает локальный мост DeepSeek, если он ещё не работает, и затем открывает панель на [http://127.0.0.1:8787](http://127.0.0.1:8787). Мост должен быть настроен заранее: по умолчанию скрипт ищет соседнюю папку `DeepSeek-Api-Free` с `.env` и виртуальным окружением `.venv`. Другую папку можно указать переменной `DEEPSEEK_BRIDGE_DIR` или файлом `scripts/.deepseek-bridge-path.local`.

В `.env` моста задайте `API_KEY`, `HOST=127.0.0.1`, `MEMORY_MODE=client` и `HEADLESS=false`. При первом использовании войдите в DeepSeek в открывшемся окне. Сессия браузера хранится локально.

Для ручного запуска панели без скрипта:

```bash
go run . --web
```

В этом случае DeepSeek bridge должен быть запущен отдельно и доступен по адресу `http://127.0.0.1:8000/v1`. Панель слушает только локальный компьютер. Остановить её можно сочетанием `Ctrl+C` в терминале.

## Как начать работу

1. Откройте **Профиль**, заполните данные кандидата или прикрепите резюме, проверьте результат и сохраните профиль.
2. В **Поиске** укажите должность и условия. Выберите город из подсказок или оставьте поле пустым для поиска по России.
3. Укажите лимит подходящих вакансий и минимальную оценку соответствия от 0 до 10. При оценке 0 порог отключён.
4. При первом входе нажмите **«Только войти на hh.ru»** и авторизуйтесь вручную. Поиск после входа автоматически не начинается.
5. Оставьте автоотклики выключенными для обычного поиска. Включайте их отдельно, если хотите отправлять отклики; проверяйте результат на hh.ru.
6. Используйте **Ответ HR** для подготовки черновика ответа, а **Ментор** — для оценки навыков, плана и практики.

## Персональные данные

Профиль, план ментора и сессия hh.ru хранятся на компьютере пользователя. Файл резюме используется для извлечения данных и не сохраняется приложением как исходный файл. Для анализа и генерации нужные поля профиля, тексты вакансий и сообщения передаются DeepSeek через подключённый мост и обрабатываются инфраструктурой DeepSeek. Мост работает на компьютере пользователя, но это не означает, что сама модель работает локально.

В нижней части приложения доступны документы **«Политика обработки персональных данных»** и **«Согласие на обработку персональных данных»**. Это шаблоны для локальной версии, а не юридическое подтверждение соответствия требованиям 152-ФЗ и не зафиксированное приложением согласие. До публичного запуска оператору нужно заполнить данные и проверить документы по фактической схеме обработки, включая используемого AI-провайдера. Приложение пока не фиксирует подписание согласия.

Локальные пользовательские данные исключены из Git. Не добавляйте в репозиторий резюме, cookies, пароли, API-ключи или данные других людей.

## Где находятся локальные данные

- Профиль: `data/resume.local.json`.
- План и прогресс ментора: `data/mentor.plan.json`.
- Сессия браузера hh.ru: `~/.ai-job-agent/profile`.
- Личные примеры сопроводительных писем, если созданы: `data/cover-letter-examples.local.json`.

## Ограничения

- Проект работает локально и не имеет общей базы аккаунтов или синхронизации между пользователями.
- Поиск, оценка, разбор резюме и функции ментора требуют доступной модели.
- Содержимое ответов модели может быть неточным. Проверяйте оценки, советы, письма и все факты в адаптированном резюме.
- hh.ru может менять интерфейс, ограничивать автоматизацию, запрашивать CAPTCHA или требовать ручного подтверждения. Автоматизация поддерживает основные сценарии, но не гарантирует успешный отклик для каждой вакансии.
- Отклики отправляются только при включённой настройке. Ответы в чаты работодателей автоматически не отправляются.

## Запуск из терминала

Поиск без автооткликов:

```bash
go run . --task="найди вакансии Go-разработчика в Казани" --headless=false
```

Включить автоотклики:

```bash
go run . --task="найди вакансии Go-разработчика в Казани" --headless=false --auto-apply
```

Открыть hh.ru для ручного входа:

```bash
go run . --login-only
```

Основные параметры: `--web`, `--web-addr`, `--task`, `--headless`, `--auto-apply`, `--application-target`, `--vacancy-limit`, `--min-score`, `--profile`, `--resume`, `--model-url`, `--model`, `--area`, `--login-only`.
