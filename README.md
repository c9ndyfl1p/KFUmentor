# AI Job Agent

Локальное приложение для поиска вакансий на hh.ru, оценки их по профилю кандидата и подготовки сопроводительных писем. Управление — через веб-панель в браузере; сам агент и профиль работают на вашем компьютере.

## Возможности и ограничения

- Поиск по запросу и выбранному региону hh.ru; модель может преобразовать запрос в несколько близких формулировок, а результаты объединяются без дублей.
- Оценка вакансий по полному описанию и локальному профилю кандидата.
- Подготовка сопроводительных писем по резюме и вакансии. Письма проверяются на неподтверждённые факты; если модель не может подготовить или проверить текст, отклик отменяется.
- Необязательная отправка откликов после явного включения переключателя. Отклик отправляется, только если модель рекомендует его и оценка не ниже 7/10.
- Если в форме отклика нет поля сопроводительного, агент подтверждает отправку отклика, открывает карточку этой вакансии в «Моих откликах» и пытается добавить письмо через чат.
- Ход поиска показывает отдельную карточку каждой вакансии: этап обработки, оценку соответствия и результат.
- Черновик ответа на сообщение HR. Приложение не отправляет этот ответ: его нужно проверить, скопировать и вставить в чат hh.ru вручную.
- Ручной вход в hh.ru в отдельном окне и кнопка остановки текущей задачи.

Формы hh.ru отличаются по вакансиям: письмо может вводиться вместе с откликом, добавляться после него в чате или требовать отдельного действия. Автоматизация поддерживает основные варианты, но не все состояния сайта. После работы проверяйте статус в разделе [«Мои отклики»](https://hh.ru/applicant/vacancy_response) и сам чат. Если hh.ru требует сделать резюме видимым работодателям или пройти CAPTCHA, выполните действие вручную либо остановите задачу. Агент не меняет настройки приватности за вас.

Это локальный MVP, а не полностью автономная платформа: нет базы пользователей, фоновой очереди, автоматической отправки HR-сообщений, подготовки к интервью и сопровождения офферов. Изменения сайта hh.ru могут нарушить автоматизацию.

## Запуск приложения

### Требования

- Go **1.24.3 или новее**.
- Доступ к hh.ru и к выбранному серверу модели.
- Chromium для Playwright.

Установите браузер Playwright из корня проекта:

```bash
go run github.com/mxschmitt/playwright-go/cmd/playwright@v0.6201.1 install chromium
```

На Linux дополнительно могут понадобиться системные библиотеки Chromium, перечисленные в документации Playwright для вашей системы.

### Откройте панель

Из корня проекта запустите:

```bash
go run . --web
```

Откройте [http://127.0.0.1:8787](http://127.0.0.1:8787). Панель слушает только локальный компьютер. Остановить сервер панели можно сочетанием `Ctrl+C` в терминале.

Если порт занят, задайте другой:

```bash
go run . --web --web-addr=127.0.0.1:9000
```

### Первый вход на hh.ru

1. Нажмите **«Только войти на hh.ru»**.
2. В открывшемся окне войдите в свой аккаунт вручную.
3. Закройте окно после входа. Поиск автоматически не начнётся.

Сессия браузера хранится локально в `~/.ai-job-agent/profile`. Не удаляйте эту папку, если хотите сохранить вход. Не передавайте её другим людям.

## Подключение модели

По умолчанию приложение использует Ollama по адресу `http://localhost:11434` и установленную локально модель `qwen2.5:1.5b`.

1. Установите и запустите [Ollama](https://ollama.com/download).
2. Загрузите модель:

   ```bash
   ollama pull qwen2.5:1.5b
   ```

3. Запустите панель с настройками по умолчанию:

   ```bash
   go run . --web
   ```

Для другой модели Ollama передайте её имя и адрес сервера при запуске:

```bash
go run . --web --model-url=http://localhost:11434 --model=qwen2.5:3b
```

Также поддерживаются серверы с OpenAI-совместимым API `chat/completions`. Для этого укажите базовый URL, заканчивающийся на `/v1`, и точный идентификатор модели, который принимает этот сервер:

```bash
go run . --web --model-url=http://MODEL_HOST:PORT/v1 --model=MODEL_ID
```

Адрес модели должен быть доступен компьютеру, на котором запущено приложение. Для OpenAI-совместимого режима укажите сервер, который принимает запросы без дополнительного API-ключа: настройка ключа в приложении пока не предусмотрена. Не публикуйте адреса с токенами и другие секреты в README.

Проверить доступность Ollama можно так:

```bash
ollama list
curl http://localhost:11434/api/tags
```

Если панель открывается, но поиск или генерация ответа завершаются ошибкой соединения, проверьте адрес и доступность модели с той же машины, где запущена панель.

## Работа в панели

### 1. Заполните профиль

Профиль находится справа. Заполните имя, желаемую должность, краткое описание, навыки через запятую и опыт — по одному месту работы на строку. Нажмите **«Сохранить профиль»**.

Чтобы импортировать профиль, нажмите **«Прикрепить резюме»** и выберите JSON, текстовый PDF или Word DOCX размером до 10 МБ. PDF поддерживается до 20 страниц и 24 000 символов извлечённого текста; для PDF и DOCX нужна запущенная локальная модель. После разбора откроется редактируемый предпросмотр, а профиль заменится только после нажатия «Сохранить профиль». Сканы PDF без текстового слоя и старый формат DOC пока не поддерживаются. Можно отдельно заполнить личные достижения: награды, конкурсы, результаты и ссылки. Структура JSON:

```json
{
  "name": "Имя Фамилия",
  "title": "Backend-разработчик",
  "summary": "Краткое описание опыта и специализации",
  "experience": [
    {
      "position": "Backend-разработчик",
      "company": "Компания",
      "period": "2022–2025",
      "responsibilities": ["Разрабатывал сервисы", "Работал с PostgreSQL"]
    }
  ],
  "skills": ["Go", "PostgreSQL", "Docker"],
  "education": [],
  "languages": [],
  "contact": {
    "email": "name@example.com",
    "phone": "+7 ...",
    "linkedin": "",
    "github": ""
  }
}
```

Для автооткликов необходимы имя, должность и хотя бы один навык. Указывайте только реальные сведения: модель использует их при оценке и подготовке писем.

### 2. Найдите вакансии

1. В поле задачи напишите должность и условия, например: `Найди 5 удалённых вакансий Python-разработчика уровня junior`.
2. При необходимости начните вводить город и выберите один из вариантов hh.ru. Если оставить поле пустым, поиск пойдёт по всей России. Если город введён, но подсказка не выбрана, запуск не состоится.
3. Для первого запуска или ручного контроля включите **«Открыть окно браузера»**.
4. Нажмите **«Начать поиск»**. В блоке **«Ход поиска»** появится карточка каждой вакансии со статусом, этапом и оценкой. Кнопка **«Очистить»** убирает карточки с экрана.

Количество вакансий можно указать в задаче; по умолчанию агент ищет до 5, максимум — 20. Поиск зависит от доступности hh.ru и модели.

### 3. Автоотклики

Оставьте переключатель **«Отправлять отклики»** выключенным, чтобы только искать и оценивать вакансии. Включайте его отдельно для конкретного запуска, если действительно хотите отправить отклики из вошедшего аккаунта hh.ru. Агент применяет порог оценки 7/10 и рекомендацию модели `apply`. Если поле письма отсутствует в форме, агент переходит в карточку отклика и пытается добавить письмо через чат; проверяйте итоговый статус и переписку в hh.ru.

Кнопка **«Остановить»** завершает активный процесс агента. После остановки проверьте «Мои отклики» перед повторным запуском: процесс мог прерваться уже после отправки отклика.

### 4. Ответ работодателю

В блоке **«Переписка с работодателем»** укажите вакансию, компанию, при необходимости добавьте предыдущий контекст и вставьте сообщение HR. Нажмите **«Подготовить ответ»**. Проверьте черновик, отредактируйте при необходимости, скопируйте его и отправьте вручную в чате hh.ru. Ответ не отправляется автоматически.

## Где хранятся данные

- Профиль из веб-панели: `data/resume.local.json`.
- Сессия hh.ru: `~/.ai-job-agent/profile`.
- Журнал панели хранится в памяти процесса и доступен, пока панель запущена.

Профиль и сессия не отправляются в облако самим приложением. Данные профиля передаются выбранной модели для анализа вакансий и подготовки текста. Не добавляйте личный профиль, cookies, пароли или ключи в Git.

### Примеры стиля писем

Можно создать рядом с JSON-файлом профиля файл `cover-letter-examples.local.json` с 1–5 примерами одобренных писем:

```json
[
  {
    "vacancy": "Краткое описание вакансии",
    "letter": "Текст письма, стиль которого вам подходит"
  }
]
```

Для профиля панели путь к файлу: `data/cover-letter-examples.local.json`. Примеры задают стиль, но факты о кандидате берутся из текущего профиля; веса модели не обучаются. Личные примеры исключены из Git.

## Запуск из терминала

Поиск без отправки откликов:

```bash
go run . --task="найди вакансии Go-разработчика в Казани" --headless=false
```

Явно включить автоотклики:

```bash
go run . --task="найди вакансии Go-разработчика в Казани" --headless=false --auto-apply
```

Открыть hh.ru только для ручного входа:

```bash
go run . --login-only
```

Основные параметры: `--web`, `--web-addr`, `--task`, `--headless`, `--auto-apply`, `--application-target`, `--vacancy-limit`, `--debug`, `--profile`, `--resume`, `--model-url`, `--model`, `--area`, `--login-only`, `--interactive`.

## Если что-то не работает

- **Не загружается список городов:** проверьте доступ к `api.hh.ru`; можно очистить поле города и искать по всей России.
- **Не открывается Chromium:** установите браузер командой Playwright выше; на Linux проверьте системные зависимости.
- **Модель не отвечает:** проверьте адрес API, имя модели и доступность сервера с этой машины.
- **Отклик или сопроводительное не появились:** проверьте «Мои отклики» и соответствующий чат hh.ru. Не запускайте повторно, пока не убедитесь, что отклик не был отправлен.
- **hh.ru просит CAPTCHA, подтверждение или изменить видимость резюме:** выполните действие вручную; автоматический обход не поддерживается.

## Желаемое количество откликов

Включите «Отправлять отклики» и укажите желаемое количество от 1 до 100
(по умолчанию — 5). Это число подтверждённых новых откликов, а не число
просмотренных вакансий. После достижения цели агент остановит поиск. Сам текст
задачи не включает автоотклики: переключатель нужно включить отдельно.

Агент просматривает следующие страницы поиска и убирает дубли вакансий,
найденные по нескольким запросам. Он учитывает неподходящие вакансии и уже
отправленные отклики, если hh.ru показывает соответствующий статус. За один
запуск проверяется до 10 страниц на поисковый запрос. Если вакансий для цели
не хватит, агент покажет фактическое число подтверждённых откликов. При
неподтверждённой отправке поиск остановится: проверьте «Мои отклики» перед
повторным запуском.

Из командной строки:

```bash
go run . --task="найди вакансии Go-разработчика" --auto-apply --application-target=10 --headless=false
```

Отдельно задайте **лимит поиска вакансий** от 1 до 100 в панели или через
`--vacancy-limit`. Он ограничивает количество уникальных вакансий, которые агент
обработает, и действует как при обычном поиске, так и при автооткликах. При
автооткликах поиск остановится при достижении лимита просмотренных вакансий или
желаемого числа подтверждённых откликов. По умолчанию лимит поиска — 5.
